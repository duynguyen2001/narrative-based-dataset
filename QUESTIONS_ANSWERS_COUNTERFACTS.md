# Questions, Answer Choices, and Counterfacts Guide

## Overview

This document focuses on the three key fields in the dataset:
- **`question`** - The prompt asking about the story
- **`answer_choices`** - Multiple choice options with types and correctness
- **`counterfact`** - Generated global counterfactual fact explaining state change

---

## Field Structures

### 1. Question Field

```json
{
  "question": "Here are the story lines:\nJimmy was working on his roof on a hot afternoon.\nHe went to step on a part of the roof and stepped on a soft spot.\nHis foot went straight through the roof and he got stuck.\nJimmy spent 45 minutes trying to get loose.\nEventually his wife came home and helped him out.\n\nQuestion: Based on the globally defined rules, how does the story evolve?"
}
```

**Format:**
- Presents all 5 original story lines
- Ends with a question prompt asking students to determine how the story evolves
- Implicitly tests understanding of implicit assertions in the narrative

**Purpose:**
- Provides context for the multiple choice question
- Tests whether the student can identify the correct assertion from the story

---

### 2. Answer Choices Field

```json
{
  "answer_choices": [
    {
      "text": "I cared what others thought.",
      "type": "misapplied_rule_distractor"
    },
    {
      "text": "Jim is not yet in a relationship.",
      "type": "near_miss_distractor"
    },
    {
      "text": "Jim is married.",
      "type": "standard_trap"
    },
    {
      "text": "Jim is unmarried.",
      "type": "correct"
    }
  ],
  "correct_choice_index": 3
}
```

**Answer Choice Types:**

| Type | Description | Example |
|------|-------------|---------|
| **`correct`** | The right answer (index 3 in most cases) | "Jim is unmarried" |
| **`standard_trap`** | Directly contradicts the counterfact; common wrong answer | "Jim is married" (original state) |
| **`near_miss_distractor`** | Partially correct but not the counterfact | "Jim is not yet in a relationship" |
| **`misapplied_rule_distractor`** | Irrelevant or semantically unrelated | "I cared what others thought" |

**Fields:**
- **`text`** - The answer choice text
- **`type`** - Classification of the choice
- **`correct_choice_index`** - 0-indexed position of correct answer (usually 3)

---

### 3. Counterfact Field

```json
{
  "counterfact": "All marriage ceremonies worldwide have been temporarily banned due to a global pandemic of mythical creatures that interfere with wedding rituals."
}
```

**Characteristics:**
- Generated by an LLM (Qwen2.5-7B-Instruct)
- Explains WHY the story state changed
- Global-scale assumption (e.g., "All... worldwide...")
- Counterfactual - describes a world different from reality
- Directly addresses the modified assertion

**Examples:**

| State → Modify State | Generated Counterfact |
|---------------------|----------------------|
| "Jim is married" → "Jim is unmarried" | "All marriage ceremonies worldwide have been temporarily banned due to a global pandemic of mythical creatures..." |
| "His wife is able to assist" → "His wife is unable to assist" | "All global telecommunications systems suddenly went silent for 30 minutes." |
| "Tina is squeamish" → "Tina is not squeamish" | "A global health crisis has completely desensitized all humans to horrific sights..." |

---

## Related Fields

### State and Modify State

```json
{
  "state": "Jim is married.",
  "modify_state": "Jim is unmarried.",
  "counterfact": "All marriage ceremonies worldwide have been temporarily banned..."
}
```

- **`state`** - Original implicit assertion from the story
- **`modify_state`** - Counterfactual assertion (what would need to be true)
- **`counterfact`** - The generated explanation for the state change

## Processing These Fields

### Loading and Extracting

```python
import json

def load_results(filepath):
    """Load result file."""
    with open(filepath, 'r') as f:
        return json.load(f)

# Load data
results = load_results('counterfact_result_val_qwen3.with_mc.json')

# Extract question, choices, and counterfact
for item in results[:5]:
    print(f"Question:\n{item['question']}\n")
    
    print("Answer Choices:")
    for i, choice in enumerate(item['answer_choices']):
        marker = " ✓" if i == item['correct_choice_index'] else ""
        print(f"  {i}. {choice['text']} ({choice['type']}){marker}")
    
    print(f"\nCounterfact: {item['counterfact']}\n")
    print("-" * 80)
```

### Filtering by Answer Type

```python
def filter_by_choice_type(results, choice_type):
    """Filter results containing a specific choice type."""
    filtered = []
    for item in results:
        choice_types = [c['type'] for c in item['answer_choices']]
        if choice_type in choice_types:
            filtered.append(item)
    return filtered

# Get all items with near-miss distractors
near_miss = filter_by_choice_type(results, 'near_miss_distractor')
print(f"Items with near-miss distractors: {len(near_miss)}")

# Get all items with misapplied rule distractors
misapplied = filter_by_choice_type(results, 'misapplied_rule_distractor')
print(f"Items with misapplied-rule distractors: {len(misapplied)}")
```

### Analyzing Counterfacts

```python
from collections import Counter
import re

def analyze_counterfacts(results):
    """Analyze counterfact patterns."""
    counterfacts = [item['counterfact'] for item in results]
    
    # Length statistics
    lengths = [len(cf.split()) for cf in counterfacts]
    
    # Common keywords
    all_words = ' '.join(counterfacts).lower().split()
    word_freq = Counter(all_words)
    
    # Global scale indicators
    global_keywords = ['all', 'worldwide', 'global', 'every', 'everyone', 'everywhere']
    global_count = sum(1 for cf in counterfacts if any(kw in cf.lower() for kw in global_keywords))
    
    return {
        'total_counterfacts': len(counterfacts),
        'unique_counterfacts': len(set(counterfacts)),
        'avg_length': sum(lengths) / len(lengths),
        'min_length': min(lengths),
        'max_length': max(lengths),
        'most_common_words': word_freq.most_common(20),
        'global_scale_counterfacts': global_count,
        'global_percentage': global_count / len(counterfacts) * 100
    }

analysis = analyze_counterfacts(results)
print(f"Total counterfacts: {analysis['total_counterfacts']}")
print(f"Unique counterfacts: {analysis['unique_counterfacts']}")
print(f"Average length: {analysis['avg_length']:.1f} words")
print(f"Global scale: {analysis['global_percentage']:.1f}%")
print(f"\nTop 10 most common words:")
for word, count in analysis['most_common_words'][:10]:
    print(f"  {word}: {count}")
```

### Creating Training Examples

```python
def create_training_examples(results):
    """Create training examples from questions and counterfacts."""
    examples = []
    
    for item in results:
        # Question-Counterfact pair
        example = {
            'question': item['question'],
            'counterfact': item['counterfact'],
            'correct_answer': item['answer_choices'][item['correct_choice_index']]['text'],
            'correct_choice_index': item['correct_choice_index'],
            'all_choices': [c['text'] for c in item['answer_choices']],
            'choice_types': [c['type'] for c in item['answer_choices']],
            'state_change': f"{item['state']} → {item['modify_state']}"
        }
        examples.append(example)
    
    return examples

train_examples = create_training_examples(results)

# Export to CSV for annotation tools
import csv
with open('qwen3_qa_counterfacts.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.DictWriter(f, fieldnames=['state_change', 'question', 'counterfact', 'correct_answer', 'all_choices'])
    writer.writeheader()
    for ex in train_examples[:100]:
        writer.writerow({
            'state_change': ex['state_change'],
            'question': ex['question'][:200] + '...',
            'counterfact': ex['counterfact'],
            'correct_answer': ex['correct_answer'],
            'all_choices': ' | '.join(ex['all_choices'])
        })
```

## Use Cases

### 1. Multiple Choice Testing
Use the `question` and `answer_choices` to test student understanding:
- Present question with 4 answer choices
- Student selects correct choice
- Compare with `correct_choice_index`

### 2. Counterfact Generation Training
Train models to generate counterfacts given state changes:
- **Input:** `state` + `modify_state`
- **Output:** `counterfact`
- **Evaluation:** Semantic similarity to generated counterfact

### 3. Answer Choice Classification
Classify answer choices by type (harder task):
- **Input:** Answer choice text + question context
- **Output:** Choice type (`correct`, `standard_trap`, etc.)

### 4. Question Answering
Train QA models with modified stories:
- **Input:** `modified_story_lines` + `question`
- **Output:** Correct choice from `answer_choices`

## Example Statistics Query

```python
def get_statistics(results):
    """Get comprehensive statistics."""
    
    # Counterfact keywords
    counterfacts = [r['counterfact'] for r in results]
    
    # State changes
    state_changes = [(r['state'], r['modify_state']) for r in results]
    
    # Story titles
    titles = Counter(r['title'] for r in results)
    
    # Choice distribution by type
    all_choice_types = []
    for item in results:
        for choice in item['answer_choices']:
            all_choice_types.append(choice['type'])
    
    choice_type_dist = Counter(all_choice_types)
    
    return {
        'total_items': len(results),
        'unique_counterfacts': len(set(counterfacts)),
        'unique_state_changes': len(set(state_changes)),
        'most_common_stories': titles.most_common(10),
        'choice_type_distribution': dict(choice_type_dist),
        'avg_counterfact_length': sum(len(cf.split()) for cf in counterfacts) / len(counterfacts)
    }

stats = get_statistics(results)
print(f"Total items: {stats['total_items']}")
print(f"Unique counterfacts: {stats['unique_counterfacts']}")
print(f"Choice type distribution:\n{stats['choice_type_distribution']}")
print(f"Average counterfact length: {stats['avg_counterfact_length']:.1f} words")
```

## Key Takeaways

1. **Questions** present story context and ask for implicit assertion interpretation
2. **Answer Choices** are 4 multiple choice options with different distractor types:
   - Correct (the modified assertion)
   - Standard trap (the original assertion)
   - Near miss (partially related)
   - Misapplied rule (irrelevant)
3. **Counterfacts** explain WHY the state changed from original to modified
4. Each item tests understanding through all three components together
